# 游戏设计

## 定位

Dashline 是一款纯单机每日跑酷游戏。核心目标是用很低的操作门槛提供短局、快速重开的个人挑战体验。

## 核心循环

```text
进入今日赛道 → 跑酷与收集 → 完赛或撞毁 → 保存个人最佳
       ▲                                      │
       └──────── 再跑一次 / 强化天赋 ─────────┘
```

## 操作

- 轻点：短跳。
- 长按：更高、更远的蓄力跳。
- S、下滑：空中下砸。
- D、右滑或双击：空中冲刺。
- P：暂停。
- R：重新开始。

## 单机成长

- 今日最佳：保存在当前浏览器。
- 连续完赛：只有完成每日赛道才累计，失败记录不计入连续天数。
- 衣橱：用赛道中收集的宝石解锁外观。
- 成就：根据完赛、收集、护盾和技巧触发。
- 天赋：永久强化护盾、磁铁、金币和冲刺能力。

天赋只影响玩家自己的单机体验，因此不需要处理竞技公平或服务端重放一致性。

## 复活机制

撞毁（含坠坑）后，结算面板会尽可能给出复活入口，让一局能接着跑下去：

- **免费复活**：每天 3 次，按 UTC 日期日切，纯单机环境也始终可用；
- **激励广告复活**：仅 4399 运营环境且广告有库存时出现，每局最多一次，不占用免费次数；
- 两条入口都在同一局内可继续，不影响「再跑一次」；
- 复活回到最近的安全落地检查点。检查点只在**踩实地面**时取样，并且**滞后约 320px（约 12.8m、0.9 秒路程）才提交** —— 提交那一刻玩家已经又往前跑了一段，所以复活点必定落在死亡点身后 14～30m，而不是贴着害死自己的坑口原地重生；
- 复活后获得约 2 秒保护，可抵挡尖刺、钉球和激光，但**坠坑不受保护**，掉出世界会立即判死；
- 免费次数用尽且没有可用广告时，面板明确提示本轮暂无复活机会。

复活只提升单机续航，不改变每日赛道，也不引入在线排名或远程输入流。

## 每日赛道

赛道由 UTC 日期和核心版本确定。相同版本下，同一天刷新页面仍会得到同一条赛道；次日自动更换。
核心版本同时参与主题选择，因此升级核心版本会同时更换当天的赛道与配色主题。

### 赛道长度与难度节奏

- 单局赛道目标长度约 36000px（按 360px/s 计算约 100 秒），实际落点在 36000~36700px 之间。
- 难度解锁按**绝对距离**推进，而不是赛道百分比：约 2400px 后解锁一级积木、5000px 二级、
  7600px 三级、10400px 之后全部解锁。用百分比会让"拉长赛道"顺带把有趣积木推到后半程，
  等于变相拉长新手区，所以这里固定成距离门槛。
- 赛道由 26 种积木（chunk）按权重随机拼装，包含坑、尖刺、台阶、碎裂板、升降台、加速带、
  气流柱、重力门、激光闸门、横扫钉球以及四种高低地形。

### 地形起伏

地面不再是单一水平线，存在山丘、谷地、高台与连绵起伏四种地形积木。

- 高度限制：最高抬升 120px、最低下沉 40px（相对基准地面 `GROUND_Y = 460`）。
  上限受"相机只做水平跟随"约束——抬得更高会让角色跑出视口顶部；
  下限受坑深判定约束——再深会让谷底接近坠落判定线。
- 坡道用**阶梯**实现，单级台阶高差不超过 10px，玩家靠 `GROUND_STEP_MAX = 12px`
  的贴地容差自动上下坡，因此不需要斜坡碰撞体，观感也符合像素游戏风格。
- 每种地形积木在结束前都会把地面收回基准高度，所以其余积木可以继续假定地面在
  `GROUND_Y`，不必逐个适配。
