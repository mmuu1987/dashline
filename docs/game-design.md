# 游戏设计

## 定位

Dashline 是一款纯单机每日跑酷游戏。核心目标是用很低的操作门槛提供短局、快速重开的个人挑战体验。

## 核心循环

```text
进入今日赛道 → 跑酷与收集 → 完赛或撞毁 → 保存个人最佳
       ▲                                      │
       └──────── 再跑一次 / 强化天赋 ─────────┘
```

## 操作

- 轻点：短跳。
- 长按：更高、更远的蓄力跳。
- S、下滑：空中下砸。
- D、右滑或双击：空中冲刺。
- P：暂停。
- R：重新开始。

## 单机成长

- 今日最佳：保存在当前浏览器。
- 连续完赛：只有完成每日赛道才累计，失败记录不计入连续天数。
- 衣橱：用赛道中收集的宝石解锁外观。
- 成就：根据完赛、收集、护盾和技巧触发。
- 天赋：永久强化护盾、磁铁、金币和冲刺能力。

天赋只影响玩家自己的单机体验，因此不需要处理竞技公平或服务端重放一致性。

## 可选激励复活

4399 运营环境可在撞毁结算后提供一次由玩家主动选择的激励广告复活：

- 每局最多一次；
- 完整观看后才复活，取消、失败或无库存不发放；
- 不看广告始终可以直接重新开始；
- 复活回到最近的安全落地检查点，并获得约 2 秒保护；
- 本地环境或平台能力不可用时不显示广告按钮。

该能力不改变游戏的单人定位，不引入在线排名或远程输入流。

## 每日赛道

赛道由 UTC 日期和核心版本确定。相同版本下，同一天刷新页面仍会得到同一条赛道；次日自动更换。
