# 游戏设计

## 定位

Dashline 是一款纯单机每日跑酷游戏。核心目标是用很低的操作门槛提供短局、快速重开的个人挑战体验。

## 核心循环

```text
进入今日赛道 → 跑酷与收集 → 完赛或撞毁 → 保存个人最佳
       ▲                                      │
       └──────── 再跑一次 / 强化天赋 ─────────┘
```

## 操作

- 轻点：短跳。
- 长按：更高、更远的蓄力跳。
- S、下滑：空中下砸。
- D、右滑或双击：空中冲刺。
- P：暂停。
- R：重新开始。

## 单机成长

- 今日最佳：保存在当前浏览器。
- 连续完赛：只有完成每日赛道才累计，失败记录不计入连续天数。
- 衣橱：用赛道中收集的宝石解锁外观。
- 成就：根据完赛、收集、护盾和技巧触发。
- 天赋：永久强化护盾、磁铁、金币和冲刺能力。

天赋只影响玩家自己的单机体验，因此不需要处理竞技公平或服务端重放一致性。

## 复活机制

撞毁（含坠坑）后，结算面板会尽可能给出复活入口，让一局能接着跑下去：

- **免费复活**：每天 3 次，按 UTC 日期日切，纯单机环境也始终可用；
- **激励广告复活**：仅 4399 运营环境且广告有库存时出现，每局最多一次，不占用免费次数；
- 两条入口都在同一局内可继续，不影响「再跑一次」；
- 复活回到最近的安全落地检查点（只在踩实地面且已前进 120px 后才记录检查点，因此不会复活到坑里或半空）；
- 复活后获得约 2 秒保护，可抵挡尖刺、钉球和激光，但**坠坑不受保护**，掉出世界会立即判死；
- 免费次数用尽且没有可用广告时，面板明确提示本轮暂无复活机会。

复活只提升单机续航，不改变每日赛道，也不引入在线排名或远程输入流。

## 每日赛道

赛道由 UTC 日期和核心版本确定。相同版本下，同一天刷新页面仍会得到同一条赛道；次日自动更换。
核心版本同时参与主题选择，因此升级核心版本会同时更换当天的赛道与配色主题。
