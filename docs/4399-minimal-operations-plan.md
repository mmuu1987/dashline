# Dashline 4399 最简运营版方案

> 状态：最简运营版代码改造已完成主体，等待 4399 平台联调。本文描述接入 4399 的最小运营范围。
>
> 当前产品现状仍以 [AGENTS.md](../AGENTS.md)、[README.md](../README.md) 和现有代码为准。
>
> 当前阶段已实现：本地平台降级桥、宿主桥注入接口、**官方 h5mini-2.0（HTML5小游戏）API 适配器**、广告复活基础状态流、内存检查点、复活后的核心无敌保护、平台进度条上报、页面生命周期自动暂停、启动失败重试 UI，以及对应的类型/单元/浏览器端到端测试。真实广告库存、平台预览环境与审核流程尚未联调，必须等待平台资料后进行。

## 1. 目标

在尽量保留当前纯单机架构、不建设自有账号与服务端的前提下，将 Dashline 改造成可提交 4399 测试和审核的最简运营版本。

最小运营闭环：

```text
打开游戏
→ 无需登录，直接游玩
→ 撞毁后可主动观看激励广告复活一次
→ 不看或广告失败时可直接重新开始
→ 结算并将进度保存在当前浏览器
```

主要收入来源：

- 4399 激励广告分成；
- 可选的低频插屏广告分成。

## 2. 第一版成功标准

1. 玩家无需登录即可完整游玩。
2. 不观看广告也能正常结算和重新开始；每天另有 3 次免费复活。
3. 每局最多通过激励广告复活一次。
4. 只有广告完整播放后才发放复活奖励。
5. 广告取消、超时、无库存或调用失败不会卡住游戏。
6. 本地成绩、宝石、皮肤、成就和天赋继续使用 `localStorage` 保存。
7. 4399 SDK 不存在或初始化失败时，自动降级为普通单机模式。
8. 可以构建独立的审核包和正式运营包。
9. 在 4399 实际测试环境中通过启动、操作、广告和生命周期验收。

## 3. 功能范围

### 3.1 保留的现有功能

- 每日确定性赛道；
- 跳跃、长按跳跃、下砸和冲刺；
- 宝石收集、个人最佳和连续完赛记录；
- 衣橱、成就和天赋；
- 暂停、重新开始和本地战报图；
- 键盘、鼠标和触屏操作；
- 横屏适配、本地音效和背景音乐。

### 3.2 必须新增

> 以下各项均已实现并通过单元、类型、构建与浏览器端到端验证，行为细节见第 12 节。

#### 4399 平台初始化

- 启动时尝试初始化 4399 SDK；
- 设置初始化超时，失败后自动降级；
- 本地开发和其他静态网站不依赖 4399 SDK；
- 平台异常不得阻断核心游戏启动。

#### 激励广告复活

撞毁结算面板提供：

```text
[💖 免费复活（剩 N）]   ← 每天 3 次，纯单机环境也有
[▶ 看广告复活]          ← 仅运营环境且广告有库存时出现
[重新开始]
```

规则：

- 免费复活按 UTC 日期每天发放 3 次，用尽后当天不再恢复（`dl_revives_v1`）；
- 激励广告复活每局最多一次，不占用免费次数；
- 广告必须由玩家主动触发；
- 完整播放后才能复活；
- 取消或播放失败不发放奖励；
- 加载失败或无库存不消耗复活机会；
- 按钮需防止连续点击和重复调用；
- SDK 重复回调不能重复发放复活；
- 复活后提供约 2 秒保护，可抵挡尖刺、钉球和激光；坠坑不受保护，掉出世界立即判死；
- 两条复活入口都不可用时，面板提示本轮暂无复活机会；
- 玩家始终可以跳过广告并重新开始。

#### 平台生命周期

- 广告展示期间暂停游戏；
- 页面进入后台或失焦时暂停并清空持续输入；
- 页面和广告恢复后重置主循环时间累计；
- 防止恢复后发生意外跳跃、下砸或冲刺；
- 广告失败或异常关闭后安全返回结算界面。

#### 加载与错误提示

- 显示游戏资源加载状态；
- 资源加载失败时提供明确提示和重试按钮；
- WebGL/Canvas 初始化失败时显示兼容性说明；
- `localStorage` 不可用时允许临时游玩；
- 4399 SDK 和广告错误使用用户可理解的提示，不只输出控制台日志。

### 3.3 可选：低频插屏广告

仅在 4399 支持并允许时启用，第一版也可以完全不接插屏。

初始频控建议：

- 首次进入和前两局不展示；
- 每 4～6 局最多展示一次；
- 两次插屏间隔不少于 8 分钟；
- 只在结算后或玩家主动返回菜单时展示；
- 激励广告结束后一段时间内不显示插屏；
- 游戏过程中绝不弹出；
- 加载失败或无库存时直接跳过。

### 3.4 可选：最小统计

> 更新（2026-09-09）：官方 h5mini-2.0 API **不提供通用统计接口**（无 track/事件上报能力），下表事件仅在接入具备统计能力的平台能力（如后续官方要求）时才有意义；当前适配器 `track()` 为空实现。

如果 4399 强制要求或 SDK 已提供统计接口，只接入以下基础事件：

| 事件 | 说明 |
|---|---|
| `game_ready` | 游戏成功启动 |
| `run_start` | 开始一局 |
| `run_crash` | 本局撞毁 |
| `run_finish` | 本局完赛 |
| `retry` | 玩家重新开始 |
| `reward_ad_click` | 点击激励广告 |
| `reward_ad_complete` | 广告完整播放 |
| `reward_ad_cancel` | 玩家中途退出 |
| `reward_ad_fail` | 广告加载或播放失败 |
| `revive_success` | 成功复活 |
| `interstitial_show` | 插屏成功展示 |

约束：

- 不上传逐 tick 输入；
- 不上传完整存档或不必要的个人信息；
- 统计代码不进入 `packages/core`；
- 统计失败不得影响游戏。

## 4. 第一版明确不做

- 自建账号、手机号注册和登录；
- 自建服务器、数据库和运营后台；
- 云存档和多设备同步；
- 支付、充值货币和付费商城；
- 在线排行榜、好友榜和远程 Ghost；
- 实时多人或房间赛；
- 赛季、推送、远程活动配置和热更新；
- 复杂反作弊系统；
- 广告换永久皮肤、天赋或大量宝石。

这些功能只有在首版运营数据证明值得投入后再单独立项。

## 5. 存档方案

第一版继续通过当前的安全存储模块使用 `localStorage`，不建设服务端。

存储内容包括：

- 每日最佳和历史记录；
- 连续完赛天数；
- 宝石数量；
- 皮肤解锁和装备状态；
- 成就和天赋；
- 静音设置。

必须向玩家说明：

> 游戏进度保存在当前浏览器中。清除浏览器数据、更换浏览器或更换设备可能导致进度丢失。

限制：

- 本地数据可以被玩家修改；
- 不能跨设备同步；
- 不得用本地数据保存付费权益；
- 后续若加入真实货币交易，必须重新设计可信订单与权益系统。

## 6. 技术设计

### 6.1 平台适配层

当前实现（保持扁平文件，避免过早拆目录）：

```text
apps/client/src/
├─ platform.ts          # GamePlatform 稳定接口 + 平台选择优先级 + 宿主桥实现
├─ platform-h5mini.ts   # 官方 h5mini-2.0（HTML5小游戏）API 适配器
└─ platform-config.ts   # 构建期开关（VITE_DASHLINE_PLATFORM）
```

最小接口示意：

```ts
export type AdResult =
  | 'completed'
  | 'cancelled'
  | 'unavailable'
  | 'failed';

export interface GamePlatform {
  readonly kind: 'local' | '4399';
  init(): Promise<void>;
  isAvailable(): boolean;
  showRewardedAd(placement: string): Promise<AdResult>;
  showInterstitialAd(placement: string): Promise<AdResult>;
  track(event: string, data?: Record<string, string | number | boolean>): void;
  refreshAds?(): Promise<boolean>;
  reportLoadProgress?(percent: number): void;
}
```

实现分为：

- 本地实现：不加载平台 SDK，广告返回 `unavailable`；
- 官方 4399 实现：封装 h5mini-2.0（HTML5小游戏）API，见第 12 节；
- 宿主桥实现：通过 `window.__DASHLINE_PLATFORM__` 注入，供浏览器测试与自定义宿主联调。

约束：

- `packages/core` 不得依赖 4399、广告、DOM、网络或存储；
- `main.ts` 不直接散落具体 SDK 调用；
- 平台 SDK 必须通过单一适配模块访问；
- 本地直开（非 iframe 嵌入）时完全不加载平台脚本、不发起任何网络请求。

### 6.2 广告流程

```text
点击观看广告
→ 锁定按钮并清空输入
→ 暂停游戏
→ 调用平台广告
→ 等待成功、取消、不可用或失败结果
```

结果处理：

```text
完整播放 → 标记本局已复活 → 恢复角色 → 开启短暂保护 → 继续游戏
取消/失败/不可用 → 不发奖励 → 返回结算面板
```

需要处理：

- 调用超时；
- 重复点击；
- SDK 重复回调；
- 广告过程中切后台；
- 广告关闭后页面未恢复焦点；
- 游戏对象已经销毁或本局已经重开。

### 6.3 构建环境

实际实现使用单一构建变量 `VITE_DASHLINE_PLATFORM`（见 12.2 节）：

| 取值 | 行为 |
|---|---|
| `auto`（默认） | 仅在 iframe 嵌入环境接入官方 SDK；本地直开纯单机 |
| `4399` | 无条件接入官方 SDK（平台预览联调强制用） |
| `local` / `off` | 禁用一切平台能力 |

说明：

- h5mini-2.0 官方 API 无广告位 ID、无渠道参数——SDK 由官方固定公开地址加载，测试/正式环境的区分由 4399 平台侧控制，客户端无需区分审核包与运营包；
- 插屏与统计开关为代码内预留通路（当前默认不调用）；
- 不得将通信私钥、支付密钥等服务端秘密打入前端包或提交仓库（当前架构无此类秘密）。

### 6.4 管理员通道必须从平台包编译掉

GitHub Pages 演示构建默认带一个调试用的管理员通道（`?admin=<口令>` 跳过每日复活额度，见 [技术架构](./tech-architecture.md)）。**4399 审核包与运营包必须用 `VITE_DASHLINE_ADMIN=0` 构建**，否则包内会带上一条可绕过广告复活的无限复活后门：

```bash
VITE_DASHLINE_ADMIN=0 pnpm --filter @dashline/client exec vite build --base=./
grep -c dashline-admin apps/client/dist/assets/*.js   # 必须为 0
```

该变量会把整段逻辑连同口令字面量一起编译掉，因此不需要额外的运行时校验；发布前务必执行上面的 `grep` 自检。

### 12.2 适配器行为（`apps/client/src/platform-h5mini.ts`）

- **接入条件**：构建变量 `VITE_DASHLINE_PLATFORM`（默认 `auto`）——
  - `auto`：仅在页面被嵌入 iframe（4399 平台承载方式）时尝试加载官方 SDK 并接入；本地直开完全不发网络请求；
  - `4399`：无条件尝试（供平台预览页强制使用）；
  - `local` / `off`：禁用一切平台能力，保持纯单机。
- **平台选择优先级**：官方 SDK（嵌入环境）→ 宿主桥 `window.__DASHLINE_PLATFORM__`（测试用）→ 本地模式。
- **SDK 加载**：动态注入 `h5api-interface.php`，轮询等待 `h5api.playAd` 就绪（真实实现覆盖 stub 的标志）并完成 `canPlayAd` 库存探测；**脚本等待与探测共享 `initTimeoutMs`（2.5 秒）总预算**，保证平台初始化对启动的最长阻塞不超过 2.5 秒，预算耗尽后按本地模式降级（首次撞毁时会再次后台探测）。
- **库存探测**：初始化时与每次撞毁后调用 `canPlayAd` 刷新库存；异步结果返回后会重绘当前结算面板，无库存时复活入口不展示、不消耗复活机会。
- **播放映射**：`playAd` 回调可能多次触发；仅 `code=10001`（播放结束）映射为 `completed` 并发放复活，`10010`（异常）与超时（30 秒）映射为 `failed`，`10000`（开始播放）为中间状态继续等待。
- **进度上报**：资源加载期间按 `done/total` 调用 `progress(1~100)`。
- **安全降级**：SDK 缺失、脚本加载失败、`parent.h5api` 抛错（非 4399 宿主）、回调超时，全部静默降级，不向游戏主循环抛出任何异常。广告请求绑定发起时的局次，玩家等待期间重开后，旧回调会被忽略。

### 12.3 宿主桥（测试与联调备用通道）

浏览器测试与自定义宿主仍可通过注入 `window.__DASHLINE_PLATFORM__` 走桥模式：

```js
window.__DASHLINE_PLATFORM__ = {
  async init() { /* 可选 */ },
  async showRewardedAd(placement) {
    // 返回 'completed' | 'cancelled' | 'unavailable' | 'failed'
    return 'unavailable';
  },
  async showInterstitialAd(placement) { return 'unavailable'; },
  track(event, data) { /* 可选 */ },
};
```
