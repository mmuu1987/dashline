# 《鱼吃鱼》试玩感想与拆解

## 总体感想

《鱼吃鱼》最强的地方，是它把成长做成了玩家每隔十几秒就能看到的“身体变化”。吃掉小目标时是轻松的收集快感，发现自己终于能反过来吃掉刚才还要躲的鱼时，则产生很明确的翻身感。它不需要长教程，玩家看一眼尺寸和追逐关系就能开始行动。

实际体验里，乐趣并不只来自“大鱼吃小鱼”这条规则，而是来自三个循环叠在一起：短周期的连续吞噬，中周期的形态与能力进化，长周期的鱼类收集和成绩比较。这也是为什么即使移动操作很简单，一局仍然能保持目标感。

## 我觉得好玩的部分

### 成长反馈非常直接

形态变化比经验条上涨更有说服力。角色变大、更换鱼种、嘴部和轮廓改变，都会立即告诉玩家“我进入了新的捕食层级”。这一刻还会同步改变屏幕里的猎物和威胁关系，成长不是单纯加数值，而是改变玩法身份。

### 猎物和威胁不断互换

刚开始需要躲避的鱼，几次进化后会变成目标。玩家对同一种对象的态度发生反转，天然形成阶段性目标，也让早期受压迫的记忆转化为后期的满足。

### 局内事件能打断重复感

从运行记录可以看到回血、攻击、体力、视野、经验、速度、幸运、隐身、中毒、冲刺、宝箱贝壳和复活等内容。它们让“找小鱼—吃小鱼”的循环不断出现新变量，尤其是高价值宝箱和特殊状态，会迫使玩家暂时改变路线。

### 结算刺激很强

结算页使用巨大的本局得分、新纪录徽章、历史最高和百分比比较，视觉上很有冲击力。我看到的一局显示本局 19932 分、历史最高 2737，并标记为新纪录；无论历史值是否因版本或模式口径不同，这种“巨大突破”的呈现都很容易推动玩家再开一局。

### 角色表现有喜剧感

夸张的眼睛、咬合和体型变化，弱化了捕食题材的残酷感。失败和被吃也更像卡通闹剧，而不是惩罚性很强的死亡。

## 我觉得可以改进的部分

### 可吃与不可吃的判断不能只靠大小

当鱼的透视、镜头距离和夸张造型不同，纯视觉尺寸会产生误判。同阶、护甲、毒性或临时状态如果没有统一轮廓，玩家容易觉得“明明更小为什么不能吃”。同类产品应同时使用轮廓形状、颜色和威胁箭头。

### 中后期信息容易拥挤

角色变大、鱼群增多、技能特效增强后，真正致命的威胁可能被吞噬粒子、掉落物和 UI 遮住。反馈越华丽，越需要明确优先级：危险提示必须高于奖励演出。

### 复活和结算应更透明

参考体验中出现复活与强排名刺激，但如果复活条件、成绩口径或百分比来源不清晰，会削弱信任。新方案应明确每局复活上限、广告与免费资源的关系，并在网络不可用时不显示虚构排名。

### 重复吞噬需要更多路线选择

单纯依靠增加鱼种和特效，无法长期解决核心动作重复。更有效的做法是让玩家在安全吃小鱼、追击同阶、抢宝箱、走危险捷径和挑战精英之间不断选择。

### 新手保护不能变成无感放水

如果系统在玩家弱势时暗中削弱敌人，玩家会难以建立稳定规则。更好的追赶方式是提高恢复道具或低阶鱼群的出现概率，同时保持伤害和吞噬关系不变。

## 可借鉴与应避免

| 可以借鉴的设计原则 | 不应直接照搬的内容 |
|---|---|
| 频繁、可视的体型进化 | 原作鱼类模型、名称和动画 |
| 猎物与威胁身份反转 | 原作 UI 版式、图标和结算美术 |
| Buff、宝箱、复活打断节奏 | 原作具体数值、掉落表和关卡布局 |
| 大鱼小鱼的低门槛规则 | 没有真实数据支撑的排名文案 |
| 夸张卡通表演降低题材压力 | 依赖广告才能正常完成的难度曲线 |

## 对同类新作的结论

同类产品不能只做“更多鱼、更大数值”。真正值得围绕的核心是：玩家要频繁地重新判断“我现在能吃谁、谁会吃我、为了变强要冒多大风险”。《潮汐猎场》的策划案因此把重点放在六段身份变化、同阶失衡战斗、可打断宝箱、路线风险和清晰危险反馈上。
