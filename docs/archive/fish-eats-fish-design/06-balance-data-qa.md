## 配置模型

核心配置放在独立战斗模块中，不直接依赖平台登录、广告、网络请求或界面状态。

```typescript
interface SpeciesDef {
  id: string;
  tier: number;
  baseScore: number;
  hp: number;
  speed: number;
  turnRate: number;
  temperament: 'school' | 'flee' | 'ambush' | 'territorial' | 'boss';
  edibleRule?: 'normal' | 'armored' | 'toxic';
}

interface EncounterDef {
  id: string;
  minTier: number;
  maxTier: number;
  durationTicks: number;
  pressure: number;
  spawnGroups: Array<{
    speciesId: string;
    countMin: number;
    countMax: number;
    weight: number;
  }>;
}
```

配置中的时间一律用 tick，显示层再转换为秒。所有随机选择使用共享 PRNG；遍历实体时使用稳定 ID 排序，禁止依赖对象键顺序或当前帧率。

## 确定性约束

- 同一种子与同一输入序列必须得到相同的分数、生命、阶级和实体存活结果。
- AI 感知和决策不得读取渲染帧时间。
- 屏外降频不能减少随机数调用次数；可预取并丢弃不使用的随机值。
- 浮点临界判定统一使用固定容差，吞噬和伤害在同 tick 发生时按稳定优先级结算。
- 修改吞噬、AI、生成、伤害或计分规则时更新战斗规则版本。

## 结算优先级

同一 tick 内按以下顺序：

1. 输入与移动。
2. 环境约束与边界。
3. 玩家主动技能。
4. 吞噬候选收集。
5. 伤害候选收集。
6. 按实体 ID 排序结算吞噬。
7. 结算剩余伤害与死亡。
8. 经验、进化、掉落和分数。
9. 生成模拟事件供渲染消费。

若玩家在同 tick 吞噬目标并受到致命伤，先结算吞噬带来的即时治疗，再判断死亡，保证规则可复现。

## 自动化测试

### 核心单元测试

- 低一阶可吞噬、同阶需失衡、高一阶不可吞噬。
- 同 tick 多目标只吞噬头部区域最近且稳定 ID 最小的目标。
- 六段经验阈值、超额经验保留和进化治疗正确。
- 冲刺消耗、恢复、冷却和失焦暂停正确。
- Buff 刷新、替换、过期顺序稳定。
- 受击无敌和复苏只触发一次。
- 连食倍率、超时清零和体型差系数正确。
- 同种子同输入运行 10,000 tick 快照哈希一致。

### 生成测试

- 10,000 个种子均存在安全出生区和可达逃生路径。
- 前 12 秒不出现高两阶主动捕食者。
- 连续两个高压块后必有恢复或开放块。
- 宝箱不与边界、致命环境或出生区重叠。
- 单屏实体数和特效事件数不超过预算。

### 浏览器测试

- 鼠标、键盘、触摸模拟均可完成首次吞噬和冲刺。
- 横竖屏切换不丢失 held 状态，竖屏遮罩期间逻辑停止。
- 暂停、失焦、切换标签页不推进计时器。
- 结算、重开、图鉴和外观流程无死路。
- 本地存储禁用、配额不足、损坏 JSON 或云存档超时时仍能以游客模式开始游戏。
- 战报图不包含排名、在线挑战或外部链接。

## 人工验收脚本

1. 新存档进入游戏，不阅读说明，仅按视觉提示游玩 60 秒。
2. 记录首次吞噬、首次受击、首次进化所需时间和误解点。
3. 主动接近高阶鱼，验证危险预警至少有两种通道。
4. 触发同阶战斗，确认能理解失衡后吞噬。
5. 获得两个不同 Buff 和一个同类 Buff，核对叠加规则。
6. 开启宝箱并故意受击，确认开启被打断且原因清晰。
7. 使用复苏后完成或失败，核对结算原因与奖励只发一次。
8. 重开同一每日种子，验证事件骨架一致。

## 性能预算

| 项目 | 桌面目标 | 中端移动目标 |
|---|---:|---:|
| 渲染帧率 | 60 FPS | 45—60 FPS |
| 逻辑 step P95 | < 2 ms | < 4 ms |
| 同屏活动实体 | 80 | 48 |
| 同屏粒子 | 160 | 90 |
| 首次可操作时间 | < 3 秒 | < 5 秒 |
| 峰值 JS 堆 | < 180 MB | < 120 MB |

性能降级顺序为粒子数量、远景动画、屏外 AI 可视更新；不得降低逻辑频率或改变碰撞结果。
